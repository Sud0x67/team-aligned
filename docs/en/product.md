# Product Specification

Source: [Chinese version](../product.md)

## Purpose

Describe TeamAligned product positioning, core workflows, and beta priorities.

## Core Value

TeamAligned is a local-first AI collaboration workspace where users chat with single agents or multi-agent teams and execute real tasks.

## Core Surfaces

- Chat
- Management (agents, teams, MCP, skills)
- Extensions
- Settings and notifications

## Current Product Priority

Reliability and experience quality on existing features over new surface-area expansion.
