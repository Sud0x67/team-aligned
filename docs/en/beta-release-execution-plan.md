# Beta Release Execution Plan

Source: [Chinese version](../beta-release-execution-plan.md)

## Purpose

Translate beta goals into staged execution with measurable completion criteria.

## Typical Stages

- Stabilize core chat and group orchestration
- Validate notifications and provider recovery
- Complete export/backup and release prep
- Final acceptance replay and issue closure

## Completion Standard

Each stage must include verification evidence, not just code changes.
