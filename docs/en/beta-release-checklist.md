# Beta Release Checklist

Source: [Chinese version](../beta-release-checklist.md)

## Purpose

Provide a release gate list that must pass before beta publishing.

## Key Checks

- Typecheck, lint, smoke tests, and build pass
- Core chat and group flows manually verified
- Notifications validated in foreground/background policies
- Provider error handling and recovery messages confirmed
- Known issues documented with scope and mitigation

## Usage

Run this checklist at every candidate build, not only at final cut.
