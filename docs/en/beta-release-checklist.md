# Beta Release Checklist (macOS)

[中文版本](../beta-release-checklist.md)

Updated: 2026-05-03

Current version: `0.4.1-beta`

## 1. Automated Gate

Run this before every beta release:

```bash
npm run beta:check
```

`beta:check` currently covers:

- TypeScript typecheck
- ESLint
- Smoke tests
- Desktop build

Real-provider replay is the stronger release validation step. Run it when a local Provider config is available:

```bash
npm run test:provider-replay
```

Each scenario waits up to 180s by default. For slower local networks or Providers, override it temporarily:

```bash
TA_REPLAY_TIMEOUT_MS=240000 npm run test:provider-replay
```

Coverage:

- Direct chat: streaming, cancel, retry, `/clear`, image attachments, and long Markdown output.
- Team chat: explicit `@`, no-`@` speaker routing, multi-round handoff, parallel tasks, dependency waiting, image attachments, web tool invocation, cancel, and `/clear`.

## 2. Build Artifacts

Run:

```bash
npm run dist:mac
```

Check output directories:

- `apps/desktop/dist/`
- `apps/desktop/dist-electron/`

Every release must verify:

- Apple Silicon DMG / ZIP can be generated and installed.
- Intel DMG / ZIP is generated by the matching GitHub Actions runner.
- App name, version, icon, DMG background, and volume icon are correct.
- `CHANGELOG.md` includes the version summary.

## 3. Core Manual Acceptance

- [ ] First launch opens onboarding, and the API Key starts empty and required.
- [ ] Provider test failures explain what happened and how to recover.
- [ ] Direct chat streams text and can be cancelled while sending.
- [ ] Direct chat can retry the last user message, and `/clear` removes old context.
- [ ] Direct chat can understand image attachments, and failures suggest re-uploading or checking the file.
- [ ] Long Markdown, tables, and multiline code fences render correctly.
- [ ] Team chat prioritizes explicit `@` mentions.
- [ ] Team chat uses the orchestrator to select suitable Agents when there is no `@`.
- [ ] Team process messages are visible without flooding the chat.
- [ ] Team cancel and `/clear` both take effect.
- [ ] After reading a conversation, unread count, recent preview, and notification center state stay in sync.
- [ ] Foreground app state suppresses system notifications; background state can trigger them.
- [ ] Conversation data export and long-image sharing work.
- [ ] Diagnostics export includes startup / error / notification log tails.

## 4. Feedback Channels

Guide users to file GitHub Issues first:

- [GitHub Issues](https://github.com/Sud0x67/team-aligned/issues)
- Email: `jokeroller@163.com`

Ask users to include:

- Version and architecture (Apple Silicon / Intel).
- Reproduction steps and screenshots.
- Diagnostics JSON exported from Settings.
- Minimal shareable files from the relevant workspace, if any.

## 5. Known Limits

1. MCP reliability depends on third-party services; timeouts use the unified recovery copy.
2. OAuth MCP has authorization entry points and manual Client ID/Secret compatibility, but token-expiry and re-auth UX still need polish.
3. Conversation export currently supports minimal JSON / image export, not a full project archive.
4. Complex long-running team chat still needs observation, especially multi-Agent parallel work with dependency waits.
5. Node/Electron may print experimental runtime warnings, such as SQLite ExperimentalWarning; these do not block core functionality.
