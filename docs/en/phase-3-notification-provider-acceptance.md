# Phase 3 Acceptance: Notification and Provider

Source: [Chinese version](../phase-3-notification-provider-acceptance.md)

## Objective

Capture acceptance evidence for notification chain and provider error/recovery UX.

## Acceptance Scope

- Foreground/background notification policy
- In-app notification lifecycle (read/clear/scroll)
- Provider test-connection failure messages
- Runtime failure messages in single and group chat

## Result Format

Checklist-style pass/fail with notes and remaining risks.
