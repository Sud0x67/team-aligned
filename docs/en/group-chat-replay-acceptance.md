# Group Chat Replay Acceptance

Source: [Chinese version](../group-chat-replay-acceptance.md)

## Goal

Use realistic conversation replays as acceptance tests for group-chat behavior.

## Replay Focus

- Explicit `@agent` targeting
- Multi-round handoff continuity
- Parallel execution plus dependency waiting
- Natural process output while running
- Final response quality and stop conditions

## Output

Replay cases act as release evidence and regression baseline.
