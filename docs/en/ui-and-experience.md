# UI and Experience

Source: [Chinese version](../ui-and-experience.md)

## Scope

Define interaction and visual experience guidelines for TeamAligned desktop.

## Focus Areas

- Chat readability and response continuity
- Input ergonomics and command discoverability
- Run/process visibility without blocking conversation
- Notification readability and actionable feedback
- Cross-language experience consistency

## Principle

Prefer simple, natural, chat-first interactions with clear system feedback.
