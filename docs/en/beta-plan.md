# Beta Plan

Source: [Chinese version](../beta-plan.md)

## Stage Goal

Deliver a truly usable beta by polishing existing flows instead of adding new features.

## Core Directions

1. Make existing user journeys complete and reliable.
2. Fix UX issues and functional bugs on those journeys.
3. Remove temporary logic and keep the codebase maintainable.

## Required End-to-End Paths

- First launch and initial setup
- Provider setup and validation
- Single-chat execution
- Group-chat collaboration
- Skill and MCP usability
