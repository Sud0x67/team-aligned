# Chat Interaction and Orchestration

Source: [Chinese version](../chat-interaction-and-orchestration.md)

## Goal

Define chat interaction semantics and orchestration behavior for single and group conversations.

## Covered Topics

- Message flow and streaming behavior
- Slash command behavior and command UX
- Mention handling (`@`) and routing
- Group handoff and multi-round continuity
- Process visibility during execution

## Current Direction

Move from rigid centrally orchestrated turns to natural conversational handoff with bounded execution safeguards.
