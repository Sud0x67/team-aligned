# Group Execution Mode

Source: [Chinese version](../group-execution-mode.md)

## Purpose

Define when group chat enters execution mode and how work is partitioned safely.

## Main Concepts

- Work items owned by specific agents
- Parallel/serial batching with conflict checks
- Dependency-aware progression
- Bounded rounds and bounded message volume

## UX Requirement

Execution mode should feel continuous and visible, not stalled or opaque.
